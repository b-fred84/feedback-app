About This Project
=================
A simple feedback management application built with React, Vite, Context API, and JSON Server. Users can add, edit, delete, and view feedback items. The project also demonstrates React hooks, component composition, and mock API usage.
This project was built as part React course.

<br>


Features
* Add new feedback
* Delete existing feedback
* Edit feedback
* Real-time average rating calculation
* Persistent data via JSON Server (mock backend)

<br>


Technologies Used

* React (Vite)
* React Context API
* JSON Server
* JavaScript
* UUID
