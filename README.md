# Feedback Management App

A simple feedback management application built with React, Vite, Context API, and JSON Server. Users can add, edit, delete, and view feedback items. This project demonstrates React hooks, component composition, and working with a mock API. This project was built as part of a React course.

## Features

- Add new feedback items  
- Edit existing feedback  
- Delete feedback items  
- Real-time average rating calculation  
- Persistent data using JSON Server (mock backend)  

## Technologies Used

- **React (Vite)** – Frontend framework  
- **React Context API** – State management  
- **JSON Server** – Mock backend for data persistence  
- **JavaScript (ES6+)** – Core language  
- **UUID** – Unique ID generation
